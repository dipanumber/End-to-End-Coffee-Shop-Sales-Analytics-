# End-to-End-Coffee-Shop-Sales-Analytics
## 1. Project Overview
This project focuses on analyzing coffee shop sales. The analysis focuses on sales performance across different store locations, time periods, product categories, and customer purchasing patterns. SQL was used for data analysis and querying, Excel for data cleaning and preparation, and Power BI for interactive visualization and dashboard development. 
### The primary business question is:
How can the coffee shop leverage its sales data to identify trends, optimize operations, and improve overall business performance?
## 2. Dataset Summary
### Dataset Size
- Rows: 149,116, 

- Columns: 11, 

- Period: 2023 — 6 months.

## 5. Dashboard 
Visualize various aspects of coffee sales data to gain insights into and understand key trends. 
## 6. Key Insight
- Highest sales: June (166,485).

- Largest MoM increase: June (39.97%)

- Store location that generated the highest revenue: Lower Manhattan.

- Product category that contributed the most sales: Coffee.

- Peak sales hours: 9:1:15.

- Top selling products: Coffee, tea, bakery, drinking_chocolate, flavors.
